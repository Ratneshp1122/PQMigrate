# Pinned export schemas

PQMigrate validates every D10 export offline before writing it.

- `sarif-schema-2.1.0.json`: OASIS SARIF 2.1.0 Errata 01 official JSON schema, retrieved from <https://docs.oasis-open.org/sarif/sarif/v2.1.0/errata01/os/schemas/sarif-schema-2.1.0.json>.
- `bom-1.7.schema.json`: CycloneDX 1.7 official JSON schema from specification release `1.7.1`, retrieved from <https://raw.githubusercontent.com/CycloneDX/specification/1.7.1/schema/bom-1.7.schema.json>.

The schema files retain their upstream licensing and copyright notices.
